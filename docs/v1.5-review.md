### 0.3 ICLR 2027 AI-use statements: extraction and leakage into the body (failure modes "template wording", "leakage")

`python3 scripts/review_v15_disclosures.py` (all 42,344 papers) → `results/review/disclosure_audit_2027.csv`,
`results/review/disclosure_heading_variants_2027.csv` (heading lines only).

| measure | value |
|---|---|
| papers with an AI-use-like heading (broad net) | 96.0% |
| papers whose AI heading the v2 remover (`sections.py`) matches | 94.0% |
| AI heading present but v2 matches none (statement stays in the body) | 1.9% |
| papers with a template signature sentence left in the cleaned main body | 1.9% (3.4% of papers that have any signature) |
| statement placed after the references (outside main body anyway) | 4.6% |
| cut section that hits the 5,000-char cap / overruns into figures or tables | 0.08% / 0.25% |
| median / P90 statement length (chars) | 537 / 1,168 |

Unmatched heading variants include "use of AI assistance", "disclosure of AI use", "AI disclosure
statement", "artificial intelligence (AI) use statement", "statement of AI use", "declaration of LLM
usage", and run-in headings ("AI Use Statement: In this work, …" on one line).

The 2027 template, reconstructed from a sentence census of 5,079 cut sections (1-in-8 sample), is a
fill-in with **both polarities over the same task list**: "In this work, we used generative AI tools to
⟨tasks⟩. We have not used generative AI tools to ⟨tasks⟩. Additionally, we used generative AI tools to
⟨other uses⟩. We have reviewed all AI-assisted work. We take responsibility for the final content of this
work, including text, claims or artifacts produced with the aid of generative AI." The task list
("generate synthetic data sets, help develop theoretical models or conceptual frameworks, formulate
mathematical claims, provide critical ingredients for proving mathematical claims, assist in the writing of
proofs, propose or refine hypotheses, design or provide feedback on research methodology or experiments,
implement methods, assist with translation, clean and reformat datasets, support qualitative and thematic
data analysis, interpret results") appears verbatim in the negated clause of many statements.

Consequences the reviewer will check in Lanes B/C:
1. Phrase frequencies of task names are polarity-mixed; a frequency table must split affirmed and negated
   clauses or it will rank negated template items as common uses.
2. Prose editing / readability is not in the required-disclosure task list; it tends to appear only in the
   optional "Additionally, …" sentence. "Explicit non-use" of the required tasks is therefore **not** a
   statement that no writing help was used, and "no AI use disclosed" ≠ "no AI used".
3. The 1.9% of papers whose statement survives in the body inflate any disclosure/body phrase-overlap
   measure for exactly those papers. Lane C must use a broader remover or exclude them, and show the
   overlap result with and without them.

Reading: the growth is in PDF pages, not just extracted characters, so it is not an extraction artifact.
Main-body length is roughly flat (30–36k chars, 9–11 pages, constant characters per page); reference lists add

## 1. Checklist for each gate

Lane A (Gate 1)
- [ ] Reconstruct per-year main-body and post-ref medians/percentiles from source for two years.
- [ ] Hand-check ≥10 papers' boundaries per cohort (early/late) against the raw text.
- [ ] Check NeurIPS checklist removal, NeurIPS 2021–22 separate supplementary, TMLR (no page limit).
- [x] (baseline in 0.4) Extraction change: compare `direct` page counts and characters with `omissions`; omission-marker
      density by year (tables/equations dropped from appendices undercount appendix characters).
- [x] (baseline in 0.5) Version mix: growth within under-review submissions only.
- [ ] Concentration: share of total appendix growth from the top decile of papers.
- [ ] Page-limit / supplementary-rule claims cite a source.

Lane B (Gates 2–3)
- [ ] Extraction coverage vs the 96.0% / 94.0% baseline; how run-in and variant headings are handled.
- [ ] Template vs author text: how template sentences are identified; polarity split for task phrases.
- [ ] Hand labels: sample size ≥150, stratification, who labelled, and that labels were fixed before any
      classifier was scored. Held-out set not used for prompt tuning.
- [ ] Per-class precision/recall and confusion matrix; abstention rate; negation cases specifically.
- [ ] Re-label 30 statements blind and compare.

Lane C (Gate 4)
- [ ] Body text excludes all disclosure text (including the 1.9% leaked cases) and other statements.
- [ ] Shuffled-pairing negative control matched on topic and length; class sizes and CIs reported.
- [ ] Multiple-comparison correction declared before the scan; preregistered feature list fixed in a
      commit that precedes the results commit.
- [ ] Associations survive dropping highly formulaic statements.
